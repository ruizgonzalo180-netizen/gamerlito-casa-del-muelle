# Gamerlito · Casa del muelle

La grabación recorre la casa junto al muelle, muestra la vista al agua y sigue al personaje hasta la zona de entrenamiento.

Abrí la página principal, elegí la portada y tocá **Play**. Tras la introducción empieza el video con sonido. El joystick o las teclas **WASD** desplazan la cámara, y el botón de acción o la tecla **E** saltan al siguiente momento del video. Al final, el botón permite repetir la escena.

El proyecto funciona como sitio estático desde la raíz del repositorio. También podés descargar el ZIP, extraer toda la carpeta y abrir `index.html`.
